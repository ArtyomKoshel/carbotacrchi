## Что поставлено

Запускаемый API-сборщик с файловой выдачей, сохранением состояния и ротацией прокси; инструкция —
[CHE168.md](CHE168.md). Большой JavaScript из исследовательской папки для работы не нужен.

В очередь `collector serve`, производственный ingest и интерфейс приложения che168 пока не подключён.
Для этого нужны поддержка CNY, китайский справочник/опции и выбор адаптера по источнику. Ограниченные
файловые прогоны не запускают lifecycle и не снимают автомобили с продажи.
