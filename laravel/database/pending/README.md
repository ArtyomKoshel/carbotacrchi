# Миграции следующего релиза

Здесь лежат миграции, которые **не** выполняются при деплое: Laravel читает только `database/migrations`.

- `2026_10_25_000002_drop_the_old_translation_road.php` удаляет старую дорогу: таблицы `catalog_*`, `translations`
  и колонки `lots.{make,model_group,model,badge,badge_group}_en`.
  - Вынесена из релиза справочника, чтобы до удаления оставалась возможность откатить код без потери данных.
  - Код ветки эти таблицы и колонки уже не читает и не пишет.
  - Отрепетирована на дампе прода: 1 с.
  - **Вернуть в `database/migrations/` следующим релизом**, только после «да» владельца, когда справочник проработает на проде.
