# ADR-0002 · Контракт CarLot v1 в JSON Schema

**Контекст.** Формат лота, правил и задач сейчас «понимается» отдельно в Python и PHP; изменение одной стороны молча ломает другую.

**Решение.**
- Источник правды — Pydantic v2 модели в `collector/`; из них генерируется `contracts/carlot.v1.schema.json` (коммитится).
- Python проверяет *сериализованный* вывод (ту же границу, что в проде). PHP валидирует входящие записи и свои фикстуры по тому же файлу.
- Версия контракта едет в каждой записи (`contract: "carlot/1"`). Несовместимое изменение = новая major-версия и период приёма двух версий.
- CI сравнивает схему с предыдущей версией и падает на несовместимом изменении без смены major.

**Последствия.** Расхождение форматов ловит CI, а не прод.
