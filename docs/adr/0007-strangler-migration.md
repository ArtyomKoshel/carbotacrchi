# ADR-0007 · Переход через теневой запуск

**Решение.** Strangler fig: новый сборщик разворачивается рядом со старым парсером в теневом режиме — пишет только в буфер, ядро не применяет его данные, а сверяет с тем, что записал старый парсер (поля, вердикты отбора, счётчики). Отчёт паритета — в админке. Переключение — флаг в ядре; откат — тот же флаг. Старый код удаляется только после недели стабильной работы нового.

**Последствия.** Нет «большого взрыва»; прод в любой момент можно вернуть на старый парсер.
