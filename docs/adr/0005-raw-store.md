# ADR-0005 · Сырые ответы бирж хранятся

**Контекст.** Из ответов Encar берётся ~60 полей, остальное выбрасывается. Правка разбора или новое поле требуют перекачки 200 тыс. лотов (5–12 ч, прокси, риск блокировки). Локально Encar недоступен (геоблок), тесты ходят в живой API.

**Решение.**
- RawStore — порт; реализация — бакет Railway (S3-совместимый). Хранится последний ответ на (биржа, лот, тип запроса), gzip; запись только при смене хэша. Индекс (ключ, хэш, время) — в схеме `collector`.
- Команда replay: разобрать сохранённые ответы заново без запросов к бирже.
- Сохранённые ответы — источник тестовых фикстур.

**Последствия.** Правки разбора применяются за минуты. Объём замерить на 1 000 лотах до включения на всю базу; запасной вариант — выборка 2% + лоты с ошибками разбора.
