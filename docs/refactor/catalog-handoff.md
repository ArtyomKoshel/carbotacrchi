## Правила пользователя (обязательно)

- **Ничего не подставлять.** Двигатель, привод, топливо и поколение берутся только из того, что указал Encar.
  Год поколение не выбирает. Encar не сказал — значит пусто (память `feedback_no_guessed_specs`).
- **Названия только официальные.** Никаких ИИ-переводов в справочнике.
- **Фильтры не теряют ни одной машины.** Неразобранное видно в фильтре как «не указано».
- **Прод:**
  - SELECT можно;
  - UPDATE, DELETE, INSERT и DDL — только по явному «да» на конкретное изменение, с превью числа строк;
  - пуш в `main` и изменения в Railway — только после «да».
- Коммиты без строки `Co-Authored-By` (память `feedback_commits`).
- Не предлагать кэширование поиска и версионирование API.
- Секреты прокси попадают в процесс только через `railway run` и нигде не печатаются.

## Дальше по плану

1. **Корейские марки по свежему дереву.** Это самое важное: 67% машин.
   - Пересобрать каждую марку:
     ```
     cd analysis
     python -X utf8 build_catalog_from_tree.py ../../../../analysis/data/encar_tree_2026-10.json --make 기아 --out ../laravel/resources/catalog [--write]
     ```
     Марки: `현대` (готово), `기아`, `제네시스`, `KG모빌리티(쌍용)`, `쉐보레(GM대우)`, `르노코리아(삼성)`.
     Без `--write` скрипт печатает черновик и непонятые слова.
   - Что делает `--write`:
     - перегенерирует поколения с `"source": "encar"` и `encar_models`;
     - не трогает то, что написано руками: двигатели, комплектации, спецверсии, `names`, `model_splits`, записи с `"manual": true`.
   - Как теперь собираются поколения (`03105cc`):
     - рестайлинг или гибрид без кода привязывается к поколению, которое Encar выпускал в момент его выхода
       («쏘나타 더 브릴리언트» → `YF · The Brilliant`);
     - один код кузова — одно поколение;
     - «올 뉴» и «(신형)» начинают новое поколение.
   - Проверить руками:
     - «뉴 그랜저» (1992) — это 2-е поколение, а сейчас размечено `I · New`;
     - «올 뉴 아반떼» (1998) — рестайлинг J2, а сейчас отдельное поколение;
     - метки `New (2010)` у «(신형)»: официальные коды (Accent RB, Equus VI, i30 GD…) можно дописать
       ручной записью, но только проверенные.
   - Хвосты Hyundai (`catalog:coverage --make=Hyundai`):
     - «без двигателя»: у Casper, Staria, Grand Starex, Solati в бейдже стоит комплектация или кузов и места
       («모던», «카고 5인승», «밴 3인승»). Двигатель не выдумывать, а комплектацию и места прочитать;
     - неразобранные слова: 휠체어 리프트/슬로프, 택시형/개인형/경제형, 수출형, 구조변경, 어린이보호차,
       N인승 в trim, PYL, 300VX/380VXL, 얼티밋, …에디션, 썸머 스페셜, 플러그인 HEV, E-Lite, 플러스, Fuel Cell.
   - Затем по июньскому дереву было: Kia 68%, Chevrolet 59%, Renault Korea 74%. Хвосты в основном из-за того,
     что Encar с июня переименовал модели.
   - После каждой марки: `catalog:remap`, `catalog:validate`, `catalog:reconcile --tree=<дерево>`.
