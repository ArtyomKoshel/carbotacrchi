## Кто ты и что делаем

Ты продолжаешь работу над **CarBot**: Telegram Mini App + бот + рабочий инструмент подборщиков для поиска
машин на корейской площадке **Encar**. Компания ищет машины клиентам.

**Стек:** Laravel 13 / PHP 8.4, Python 3.11 (коллектор), MySQL 8–9, Docker. Прод на Railway.

**Цель текущей работы:** платформенно-независимый **справочник** машин
**Марка → Модель → Поколение → Модификация → Комплектация**. Он нужен для фильтров и для показа машины. Требования:
- **максимально полный**: все модели, которые знает Encar;
- **только официальные названия**, без ИИ-переводов;
- **фильтры не теряют ни одной машины**;
- после внедрения **убрать «старую дорогу»**: ИИ-переводы в колонки `*_en`, `lots:normalize-from-catalog`,
  `catalog_model_trims`, `translate:run` и т.д.

Общаемся с пользователем **по-русски**. Тексты в коде, коммитах и ревью — на английском.

## Правила пользователя (нарушать нельзя)

1. **Ничего не подставлять.** Двигатель, привод, топливо и поколение берутся только из того, что указал Encar.
   - Год не выбирает поколение.
   - Нет данных — поле пустое (статус `no_engine` / «не указано»), никаких «по умолчанию».
   - Цитата пользователя: *«если Encar их не дал, значит не факт, что там точно такой же двигатель и привод»*.
   - Данные Encar — это любые поля его API и его собственное дерево категорий (см. ниже про BadgeGroup).
2. **Прод:**
   - SELECT можно;
   - UPDATE, DELETE, INSERT и DDL — только по явному «да» на конкретное изменение, перед этим превью количества строк;
   - пуш в `main`, изменения переменных и сервисов Railway — только после «да».
   - Никогда `migrate:fresh` против прода.
   - Миграции только DDL: перед nginx стоит healthcheck 30 с, бэкфиллы делать командами.
3. **Коммиты:** без строки `Co-Authored-By`. Ветку не пушить без просьбы.
4. **Не предлагать** кэширование поиска и версионирование API.
5. **Секреты:**
   - прокси и пароли попадают в процесс только через `railway run`, их не печатать и не сохранять;
   - записанный трафик Encar (`analysis/data/`) в git не коммитить.
6. **Ревью кода:** без замечаний про тесты и про устаревание ветки. Уровни: 🔴 🟠 🟡 🔵.

## Как устроен справочник

Документация: `docs/13-catalog.md`, план — `docs/refactor/catalog-migration.md` (этапы 0–6),
снимок состояния — `docs/refactor/catalog-handoff.md`.

**Три слоя:**
1. **Справочник:** `laravel/resources/catalog/reference/{make}.json` → таблицы `ref_makes`, `ref_models`,
   `ref_generations`, `ref_modifications`, `ref_complectations`, `ref_variants`; у лотов колонки `lots.ref_*_id`.
2. **Как пишет Encar:**
   - общий словарь корейских слов `laravel/resources/catalog/encar/tokens.json`;
   - файл марки `encar/{make}.json` с разделами `korean`, `names`, `model_splits`, `encar_models`, `models`, `badges`,
     `words`, `engine_prefix`, `engine_models`, **`badge_groups`** (новое).
3. **Подписи на экране:** `TaxonomyLocalizer` / `taxonomy.js`, цвета в `translations`, опции в `encar_option_catalog`.

**Иерархия Encar:** Make → ModelGroup → Model → BadgeGroup → Badge → BadgeDetail (= `lots.trim`).
- Импортные марки: в бейдже двигатель + пакет.
- Корейские марки: бейдж — двигатель или только комплектация, BadgeDetail — комплектация.
- Рестайлинг и силовую установку Encar держит **отдельной моделью** и со временем переименовывает.

**Разбор:**
- **Вариант** — хэш полей Encar `make, model, badge_group, badge, trim` (без года). Один хэш считается в PHP
  (`CatalogLinker::hash`) и в MySQL (`CatalogLinker::SQL_HASH`).
- Каждый вариант читается один раз и хранится в `ref_variants`. Варианты со статусом `manual` (ручная разметка в админке) не перечитываются.
- `App\Catalog\Encar\EncarMatcher` → `BadgeGrammar` (кузов, места, спецверсии, комплектации) → правила марки
  `App\Catalog\Rules\{Bmw,Mercedes,Audi,Porsche,Generic}Rules`. Привод и топливо — только из явных слов.
- Статусы: `matched` / `no_engine` / `unmatched`.
- В фильтре неразобранное видно как «не указано», ничего не прячется.

**Команды** (`docs/11-commands.md`):
- `catalog:coverage --make=Kia [--dump=file.json]` — доля разобранного по дампу;
- `catalog:remap` — перечитать варианты и привязать лоты, ~2 мин;
- `catalog:validate` — файлы и годы против лотов;
- `catalog:reconcile [--tree=…]` — «не теряем ни одной машины»: счётчики фильтров = БД = Encar;
- `catalog:encar-names`.

**Генератор черновиков:**
```
cd analysis
python -X utf8 build_catalog_from_tree.py ../../../../analysis/data/encar_tree_2026-10.json --make 기아 --out ../laravel/resources/catalog [--write]
```
- Без `--write` печатает черновик и непонятые корейские слова.
- `--write` перегенерирует поколения с `"source": "encar"`, `encar_models` и `badge_groups`. Ручное не трогает:
  двигатели, комплектации, спецверсии, `names`, `model_splits`, записи `encar_models` с `"manual": true`.

## Важные находки (не потерять)

1. **`lots.model` у корейских марок урезан.** Коллектор (`collector/.../encar/mapping.py`, `clean_model`) срезает
   «더 뉴», «올 뉴», «뉴» и т.п., а это и есть поколение: «올 뉴 K3» (2-е поколение) и «더 뉴 K3» (рестайлинг 1-го)
   обе записаны как «K3».
   - Оригинал лежит в `raw_data.model_kr_raw`: он есть у 100% активных лотов и совпадает с деревом Encar.
   - **Справочник теперь читает модель как `CatalogLinker::MODEL_SQL`** = `raw_data.model_kr_raw`, а если там пусто — `lots.model`.
     Это выражение используется в хэше, в выборке вариантов, в `coverage` и в `reconcile`.
   - Если точного названия нет в `encar_models`, разбор снимает маркетинговые слова (`EncarMatcher::MARKETING`)
     и ищет по `names`. Европейские «뉴 A6» и подобные остаются как были.
2. **BadgeGroup.**
   - У лотов `badge_group` пуст: поиск Encar его не отдаёт, карточка машины тоже.
   - У корейских марок бейдж часто только комплектация («더 뉴 레이» / «프레스티지»), а двигатель Encar держит в BadgeGroup («가솔린 1000cc»).
   - Генератор выгружает из дерева `badge_groups`: модель Encar → бейдж → группа, **только если бейдж стоит в одной группе**.
   - Разбор подставляет группу **только когда бейдж не называет двигатель** (`EncarMatcher::badgeGroup`).
   - Расплывчатые группы не используются: «3000cc 이상», «가솔린+LPG», «수소».
   - Все лоты «без двигателя» у корейских марок оказались однозначными по дереву.
3. **Карточка машины Encar** (`/v1/readside/vehicle/{id}`, include `CATEGORY,SPEC`) отдаёт:
   - `modelCd`, `gradeCd`, `gradeDetailCd`;
   - **официальные английские названия** `gradeEnglishName` («Prestige»), `gradeDetailEnglishName`, `modelGroupEnglishName`;
   - `spec.displacement` и `spec.fuelName`.

   Коллектор английские названия **не сохраняет**. Это готовый источник «нормальных переводов» для этапа 2:
   надо сохранять их в `raw_data`.
4. **Корейские маркетинговые слова в названиях моделей:**
   - «더 뉴», «베리 뉴» — рестайлинг;
   - «올 뉴», «디 올 뉴», «(신형)», «더 X» без «뉴» («더 K9») — новое поколение;
   - «뉴» бывает и тем и другим, спорное решается ручной записью;
   - римская цифра («카렌스 II») — как написал Encar, не обязательно поколение;
   - «N세대» — поколение «Gen N».

   В генераторе это наборы `FACELIFT`, `RENEWAL`, `ROMAN`. Рестайлинг или гибрид без кода привязывается к поколению,
   которое Encar продавал в год его выхода: период выпуска продлевается рестайлингами, допуск на перерыв в продажах 2 года.
   Ручные записи `"manual": true` уже стоят у:
   - Hyundai «뉴 그랜저» → Gen 2;
   - Kia «New 스포티지» → Gen 2;
   - KGM «티볼리 아머» → Tivoli «I · Armour»;
   - Renault «뉴SM3», «뉴SM5» → Gen 2, «뉴SM5(신형)» → Gen 3;
   - Chevrolet «마티즈 크리에이티브» → Creative, «마티즈 클래식» → All New · Classic, «더 넥스트 스파크» → The Next.

   Ручные записи — только проверенные факты.
5. **Дерево Encar** (`analysis/scrape_encar_inav_tree.py`, результат `D:\work\carbot\analysis\data\encar_tree_2026-10.json`):
   - 13 594 строки, 76 марок, 1 852 модели, у всех моделей коды и даты;
   - 15 982 запроса, 0 сбоев.
   - На пустую ветку (0 объявлений) Encar отвечает 404 через корейский прокси. Поэтому у моделей без объявлений
     бейджей в октябрьском дереве нет, зато они есть в июньском (`analysis/encar_inav_tree.json`).
   - Исправленные сегодня ошибки скрипта:
     - потоки после первой группы шли в Encar без прокси, а вне Кореи Encar отвечает 404;
     - теперь 404 считается «пусто», только если у ветки 0 объявлений;
     - один пул потоков на весь обход.
6. **Прод, 2026-10-24.**
