### Ошибка 1: `ref_generations.code varchar(20)` — коды длиннее обрезались
- **Симптом:** `catalog:remap` падал в `CatalogStore::sync`:
  `Undefined array key "generation|Hyundai|Verna|New (2005) · Transform"`. Те же 6 ошибок были в тестах.
- **Причина:** корейские метки поколений вида «New (2005) · Transform», «Gen 2 · New Impression» — 22 символа.
  MySQL обрезал их до 20, и строка не находилась по ключу.
- **Исправление:**
  - в `2026_10_24_000001_create_reference_catalog.php` `code` расширен до 40. На проде миграция ещё не выполнялась,
    поэтому правка на месте;
  - на дампе сделан тот же `ALTER`, две обрезанные строки без ссылок удалены (id 562, 779).
- Длины всего справочника проверены: модели ≤22 из 80, поколения ≤22 из 40, комплектации ≤24 из 100,
  модификации ≤33 из 80.

### Ошибка 2: `generationId()` с `null`
- **Симптом:** `CatalogStore::generationId(): Argument #3 ($code) must be of type string, null given`.
- **Причина:** правка `ad09a39` («модель без поколения остаётся под моделью») стала ставить `model_id` и без поколения,
  но `generationId()` по-прежнему вызывался.
- **Исправление:** `CatalogLinker::read` вызывает `generationId()` только при `$m->generation !== null`.

### Пункт 1 (по «да» пользователя): локальный вход без Telegram и пароля — `4f73f6e`
- **Зачем:** локально и в UI-тестах нельзя войти через бота. Мини-апп в браузере без входа блокирует поиск,
  избранное и подписки, а в админку нужен пароль.
- **Что сделано:**
  - `laravel/routes/dev.php` подключается в `bootstrap/app.php` **только при `APP_ENV=local`**, в остальных
    окружениях этих маршрутов нет (404):
    - `POST /api/auth/dev-login` выдаёт токен браузера, уже привязанный к тестовому пользователю `100000001`
      («Local tester»). Это тот же токен, что на проде привязывает бот, поэтому дальше всё идёт обычным путём;
    - `GET /dev/admin-login` — вход в `/admin` как локальный супер-админ `local`. Пароль у него случайный, им войти нельзя.
  - `ValidateTelegramAuth`: привязанный токен браузера теперь разбирается **до** локального обхода. Раньше локально
    `user_id` брался тот, что прислала страница, теперь — пользователь токена. На проде поведение то же.
  - Мини-апп: кнопка «Войти локально» (`data-testid="dev-login"`) только когда страница открыта с localhost/127.0.0.1.
  - `laravel/dev/router.php` (раньше лежал во временной папке старой сессии): мини-апп под `/miniapp/`, корень → 302 на него,
    API и админка на одном адресе, как nginx на проде. Запуск:
    `php -d extension=pdo_mysql -d extension=intl -S 127.0.0.1:8097 -t laravel/public laravel/dev/router.php`
    (из корня worktree; `laravel/.env` указывает на дамп `carbot_dump`).
  - Тест `tests/Feature/Api/DevLoginTest.php`: маршрутов нет вне `local`, токен привязан, чужой токен — 401.
- **Проверено руками в браузере:** «Войти локально» → в шапке «Local tester», выдача 138 877 машин с названиями
  из справочника; `/dev/admin-login` → `/admin` 200.
- **Замечено по ходу:** `POST /api/search` понимает марку только по-английски: `{"make":"Kia"}` → 34 850,
  `{"make":"기아"}` → 0. Фильтры передаются в поле `query`. **Проверить:** не шлют ли бот или старые подписки корейское имя марки.
