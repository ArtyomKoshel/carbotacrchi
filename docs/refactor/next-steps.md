## Где мы

- **Прод.** Справочник «марка → модель → поколение → модификация → комплектация» работает с 2026-10-25.
  - Все 140 356 активных лотов Encar привязаны; фильтры, поиск, ИИ-поиск, бот, админка, архив и подписки читают `ref_*`.
  - Старый путь (ИИ-переводы, `*_en`, `lots:normalize-from-catalog`) удалён из кода.
  - Его таблицы и колонки ещё лежат на проде (релиз 2).
- **Код.** Ветка `feat/reference-catalog`, worktree `D:\work\carbot\.claude\worktrees\release`. Прод выкатывается пушем в `main`
  (Railway собирает за ~1 мин). Пуш в `main` — только по «да» пользователя.
- **Локально.** Один стек `carbot-dev`:
  - http://localhost:8100: `/miniapp/`, `/dev/admin-login`, `/api`;
  - MySQL `127.0.0.1:3318`, база `carbot` — дамп прода.
  - Подробности — [../local-stack.md](../local-stack.md).
- **Тесты.** PHPUnit на своей базе ветки: `vendor/bin/phpunit -c phpunit.release.xml` (база `carbot_test_release`).
  Параллельные прогоны на одной тестовой базе ловят дедлоки. UI-тесты Playwright (`e2e/`) на паузе.

## Правила (коротко, полностью — в catalog-prompt.md)

- Двигатель, привод, топливо и поколение — только то, что указал Encar. Год поколение не выбирает. Неизвестное = «не указано».
- Названия — только из справочника, без ИИ-переводов.
- Фильтр не теряет ни одной машины: `catalog:reconcile` после каждой правки справочника.
- Прод:
  - SELECT можно;
  - любые записи, DDL, пуш в `main` и изменения в Railway — только по явному «да»;
  - удаление данных — с превью числа строк.
- Коммиты без строки `Co-Authored-By`.
