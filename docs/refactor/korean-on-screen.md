# Корейский текст Encar на экране: что видно и чем заменить

> Исследование 2026-10-25, прод (только SELECT), 140 356 активных лотов Encar. Код не менялся.
> Правило: двигатель, привод, топливо и поколение не угадываем — только то, что сказал Encar.

Корейских бейджей на экране почти не осталось: строку комплектации заполняет справочник (`lot.catalog`), а в API лота
нет поля `badge`. Корейского теперь больше всего в адресе, в замечаниях осмотра и в словарях цвета.

## Чем заменять — правило по случаям

**(a) Справочник знает, но показ берёт сырое.** Показывать название из справочника.
- Чип `trim` старого поиска → комплектация из `refComplectationIds` запроса (`CatalogNames` уже переводит
  «530e M 스포츠» в 530e + M Sport).

**(b) В справочнике нет записи для варианта.** Все 541 лот — «Encar names no generation»: модель известна, поколения нет,
поэтому id модификации не пишется (`ref_modifications` привязаны к поколению), хотя матчер бейдж прочитал.
| Модель | Бейдж Encar | Что матчер прочитал | Лотов |
|---|---|---|---:|
| Ford Mustang | 쿠페 / 컨버터블 / GT 쿠페 / GT 컨버터블 | кузов Coupe / Convertible, GT | 139 |
| Other Manufacturers | 기타 전기차 | Other Electric Vehicle | 45 |
| Dodge Ram Pickup / Challenger | 5.7 | модификация 5.7 | 44 |
| Ford F-150 | 3.5L / 5.0L / 2.7L | модификация | 42 |
| GMC Sierra | 드날리-X / 2500HD | комплектация Denali-X / модификация 2500HD | 31 |
| Infiniti QX60, Nissan X-Trail, Toyota Sienna … | 3.5 AWD, 2.5 4WD | модификация с приводом | ~70 |
| BMW 5 Series GT | GT ED Edition | спецверсия, двигатель не назван | 27 |
- Правило: хранить в `ref_variants` прочитанное текстом (модификация, кузов, комплектация) и показывать его,
  когда id нет: «Ford Mustang · Coupe · GT», «Dodge Ram Pickup · 5.7». В фильтре лот остаётся в «поколение не указано».
- Сейчас у 160 из 541 строка пустая и объём двигателя из бейджа (5.7, 3.5) теряется.

**(c) Слово для словаря.** Закрытые наборы, перевод без догадок.
- **Регион** (18 значений, первое слово `location`): `경기` → Кёнгидо, `서울` → Сеул, `부산` → Пусан, `대구` → Тэгу,
  `인천` → Инчхон, `전남광주` → Чолла-Намдо / Кванджу, `대전` → Тэджон, `전북` → Чолла-Пукто, `경남` → Кёнсан-Намдо,
  `충남` → Чхунчхон-Намдо, `울산` → Ульсан, `충북` → Чхунчхон-Пукто, `경북` → Кёнсан-Пукто, `광주` → Кванджу,
  `강원` → Канвондо, `전남` → Чолла-Намдо, `제주` → Чеджу, `세종` → Седжон, `부산광역시` → Пусан.
  Клиенту показывать регион; полный адрес — только в админке.
- **Осмотр**: строка «деталь(сторона): работа». Деталей ~20 (`프론트 휀더` переднее крыло, `리어 도어` задняя дверь,
  `쿼터 패널` заднее крыло, `후드` капот, `트렁크 리드` крышка багажника, `라디에이터 서포트` панель радиатора,
  `프론트 도어`, `리어 패널`, `인사이드 패널`, `프론트 사이드 멤버` лонжерон, `사이드실 패널` порог, `트렁크 플로어`,
  `프론트 패널`, `프론트 휠하우스` арка, `루프 패널` крыша, `필러 패널` стойка, `크로스 멤버` поперечина),
  стороны `좌` лев., `우` прав., `앞` перед., `중간` средн., работы `교환(교체)` замена, `판금/용접` рихтовка/сварка,
  `용접,절단` сварка/вырез, `손상` повреждение. Пример: «Переднее крыло (лев.): замена». Незнакомая деталь — оригинал.
- **Цвет салона**: данные уже английские (`Black` 84 222, `Brown` 27 911, `Beige`, `Gray`, `Red`, `Blue`, `White`,
  `Green`, `Orange`, `Yellow`), а подписи `seat_color` в `TaxonomyCatalog` и `SEAT_COLOR_RU` в `taxonomy.js` ключами
  корейские → нужны английские ключи (Black → Чёрный и т.д.).
- **Цвет кузова**: 7 корейских значений привести к нашим: `하늘색` → Blue (голубой), `담녹색` → Green, `은하색` → Silver,
  `갈대색` → Brown, `청옥색` → Blue, `자주색` → Purple, `분홍색` → Pink — в `TaxonomyNormalizer` (карта `color`), чтобы
  фильтр давал один «Зелёный», а не два.

**(d) Английское от Encar (`lots.trim_en` = `gradeDetailEnglishName`).** Заполнено у 117 128 лотов; `No Grade` у 8 870
(Encar так пишет «нет BadgeDetail», в том числе у Genesis `블랙`). На экран сейчас идёт только в запасной строке
случая (b): 287 лотов, `No Grade` среди них 0.
- Правило: `No Grade` считать пустым; в остальном `trim_en` годится как запасной вариант и как источник для сверки
  комплектаций справочника (этап 2 плана).

**(e) Не знаем, что это.** Вместо корейского — наша пометка.
- Лот без модели: «Марка · модель не указана» (марку справочник знает у всех лотов). Сейчас 1 лот.
- Бейдж, который никто не прочитал: «комплектация не указана», корейский — только в админке.
