# UI-тесты (Playwright) — на паузе

> Статус на 2026-10-25: **на паузе** по решению пользователя, вернуться после локального стека и хвостов справочника.
> Аудит остановлен на первом прогоне; ниже — что успели узнать.

## Что есть

- `e2e/` — Playwright 1.56.1, Chromium, один воркер (встроенный PHP-сервер отвечает по одному запросу), сервер на порту 8097
  поднимается сам (`laravel/dev/router.php`), база — дамп прода из `laravel/.env` (`APP_ENV=local`, вход без Telegram).
  Как запускать — `e2e/README.md`.
- Тесты только мини-аппа (`tests/miniapp.spec.ts`, 9 тестов с учётом цикла по маркам):
  - вход без Telegram;
  - на широком экране прокручиваются панели, а не страница;
  - Kia, Hyundai, BMW, Ford: модели в сумме дают марку, каждая находит своё число машин;
  - Kia Morning: поколение → модификация → комплектация сужают точно;
  - Ford: машина без поколения находится как «Поколение не указано»;
  - карточка лота называет машину по справочнику.
- Админка: тестов нет.

## Первый прогон аудита (прерван)

- Упали 5 тестов: «модели в сумме дают марку» для Kia, Hyundai, BMW, Ford и «Kia Morning … сужают точно».
  Артефакты: `e2e/test-results/*/` (снимок страницы, `trace.zip`); тексты ошибок не сохранились — прогон остановлен.
- **Причина не проверена.** Прогон шёл одновременно с `catalog:remap` на том же дампе (работа по хвостам справочника):
  числа машин менялись во время тестов. Сначала перезапустить на спокойной базе, потом разбирать.
